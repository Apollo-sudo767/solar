# Classic X11 Window Managers 🧱

Solar provides modular, declarative support for the legendary X11 tiling and stacking window manager pantheon.

______________________________________________________________________

## 🗂️ Supported X11 Window Managers

| Window Manager | Option Path | Architecture & Paradigm | Companion Tools |
| :--- | :--- | :--- | :--- |
| **i3** | `myFeatures.platforms.desktops.i3` | Manual Tiling | Picom compositor, Dmenu launcher, Stylix borders |
| **Bspwm** | `myFeatures.platforms.desktops.bspwm` | Binary Space Partitioning | `sxhkd` hotkey daemon, Picom, Dmenu |
| **AwesomeWM** | `myFeatures.platforms.desktops.awesome` | Dynamic Lua-scripted Tiling | Native Lua configuration, Picom, Dmenu |
| **XMonad** | `myFeatures.platforms.desktops.xmonad` | Dynamic Haskell Tiling | `xmobar`, `dmenu`, Picom |
| **DWM** | `myFeatures.platforms.desktops.dwm` | Dynamic C-based Tiling | Suckless `dwm`, Dmenu, Picom |
| **Openbox** | `myFeatures.platforms.desktops.openbox` | Minimalist Stacking WM | `obconf`, `picom`, Dmenu |

______________________________________________________________________

## 🛠️ Configuration Highlights

### i3 Window Manager
```nix
myFeatures.platforms.desktops.i3 = {
  enable = true;
  modKey = "Mod4";      # Mod4 (Super) or Mod1 (Alt)
  gaps = {
    inner = 8;
    outer = 4;
  };
  picom.enable = true;  # Compositing, drop shadows, and window transparency
};
```

### Bspwm (Binary Space Partitioning)
```nix
myFeatures.platforms.desktops.bspwm = {
  enable = true;
  borderWidth = 2;
  windowGap = 8;
  splitRatio = 0.52;
  picom.enable = true;
};
```

### AwesomeWM (Lua Scripted)
```nix
myFeatures.platforms.desktops.awesome = {
  enable = true;
  luaConfig = ""; # Optional custom Lua code appended to config
};
```
