# Universal Keybindings ⌨️

Core keybindings across Niri, Ghostty, Zellij, and Helix in Solar.

______________________________________________________________________

## 🌊 Niri Scrollable Wayland Compositor

The default modifier key is <kbd>Mod</kbd> (<kbd>Super</kbd> / <kbd>Windows</kbd>).

### Window & Column Management

| Action | Keybinding |
| :--- | :--- |
| **Focus Left / Right** | <kbd>Mod</kbd> + <kbd>H</kbd> / <kbd>L</kbd> (or <kbd>←</kbd> / <kbd>→</kbd>) |
| **Focus Up / Down (in column)** | <kbd>Mod</kbd> + <kbd>J</kbd> / <kbd>K</kbd> (or <kbd>↓</kbd> / <kbd>↑</kbd>) |
| **Move Window Left / Right** | <kbd>Mod</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> / <kbd>L</kbd> |
| **Move Window Up / Down** | <kbd>Mod</kbd> + <kbd>Shift</kbd> + <kbd>J</kbd> / <kbd>K</kbd> |
| **Close Window** | <kbd>Mod</kbd> + <kbd>Q</kbd> (or <kbd>Mod</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>) |
| **Fullscreen Toggle** | <kbd>Mod</kbd> + <kbd>F</kbd> |
| **Center Column** | <kbd>Mod</kbd> + <kbd>C</kbd> |
| **Expand / Shrink Width** | <kbd>Mod</kbd> + <kbd>R</kbd> / <kbd>Mod</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> |

### Workspace & Monitors

| Action | Keybinding |
| :--- | :--- |
| **Switch Workspace 1–8** | <kbd>Mod</kbd> + <kbd>1</kbd>–<kbd>8</kbd> |
| **Move Column to Workspace 1–8** | <kbd>Mod</kbd> + <kbd>Shift</kbd> + <kbd>1</kbd>–<kbd>8</kbd> |
| **Move Focus to Left/Right Monitor** | <kbd>Mod</kbd> + <kbd>Ctrl</kbd> + <kbd>H</kbd> / <kbd>L</kbd> |

### Application Launchers & System

| Action | Keybinding |
| :--- | :--- |
| **Terminal (Ghostty)** | <kbd>Mod</kbd> + <kbd>Enter</kbd> (or <kbd>Mod</kbd> + <kbd>T</kbd>) |
| **App Launcher (Fuzzel / Rofi)** | <kbd>Mod</kbd> + <kbd>Space</kbd> (or <kbd>Mod</kbd> + <kbd>D</kbd>) |
| **Interactive Screenshot** | <kbd>PrintScreen</kbd> or <kbd>Mod</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> |
| **Lock Screen** | <kbd>Mod</kbd> + <kbd>Alt</kbd> + <kbd>L</kbd> |

## ⚡ Ghostty Terminal

| Action | Keybinding |
| :--- | :--- |
| **New Tab** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> |
| **Split Horizontally** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd> |
| **Split Vertically** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> |
| **Navigate Splits** | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>H</kbd>/<kbd>J</kbd>/<kbd>K</kbd>/<kbd>L</kbd> |

## 📝 Helix Modal Editor

| Action | Keybinding |
| :--- | :--- |
| **File Picker** | <kbd>Space</kbd> + <kbd>f</kbd> |
| **Global Text Search** | <kbd>Space</kbd> + <kbd>/</kbd> |
| **Buffer / Open Tabs** | <kbd>Space</kbd> + <kbd>b</kbd> |
| **Save File** | <kbd>:w</kbd> + <kbd>Enter</kbd> or <kbd>Space</kbd> + <kbd>w</kbd> |
| **Quit** | <kbd>:q</kbd> + <kbd>Enter</kbd> |
